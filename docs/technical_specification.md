# Meili Technical Specification

## Project summary

Meili is a behavioural decision system for urban navigation. It allows users to compare Fastest, Balanced, and Safest route options, then records how they trade off travel time and perceived safety.

## Scope rule

The MVP focuses on route comparison, route-choice logging, feedback, safety scoring, routing logic, and behavioural analytics. Features that do not directly support these goals are postponed.
